---
title: النطاقات المخصصة
description: امنح صفحة الحالة نطاقها الخاص، واجعل الوكيل يُصدر شهادته عند الطلب لصفحة منشورة فقط.
---

يمكن أن يكون لصفحة الحالة نطاقها الخاص، تضبطه في محرِّر الصفحة. وجّه DNS النطاق إلى الخادوم، فيقدّمه الوكيل كما يقدّم العنوان الرئيسي. ولا يجوز أن يكون النطاق المخصص هو مضيف العنوان العام.

تأتي شهادته من الوكيل. يُصدرها Caddy عند الطلب: عند أول زيارة للنطاق يسأل راقبَ أولًا على `GET /api/custom-domain?domain=<host>`، ولا يجيب راقب بـ 200 إلا إذا كانت صفحة حالة منشورة تحمل ذلك النطاق. فلا يحصل على شهادة نطاقُ غريب وُجّه إلى الخادوم، ولا نطاقُ صفحة لم تُنشر بعد. يفعل `deploy/Caddyfile` هذا لملف compose. وعلى الخادوم نفسه:

```text title="Caddyfile"
{
	on_demand_tls {
		ask http://127.0.0.1:3000/api/custom-domain
	}
}

raaqeb.example.com {
	reverse_proxy 127.0.0.1:3000
}

https:// {
	tls {
		on_demand
	}
	reverse_proxy 127.0.0.1:3000
}
```

مع Nginx أو Traefik، يحتاج كل نطاق مخصص شهادته الخاصة في إعداد الوكيل، كما يحتاجها العنوان الرئيسي. وعلى Fly.io: `fly certs add <domain>` (انظر دليل Fly).
