This guide is for the operator who installs Raaqeb on a server and keeps it running. It covers each way to install it, the settings it reads before it opens its database, the reverse proxy in front of it, custom status page domains, databases and backups, moving an install, upgrades and the commands the binary takes.

Raaqeb is one process. It needs no other service: SQLite in its data directory is the default database. A reverse proxy in front of it ends TLS. One install runs one process; never run two against the same database, since each would check every monitor and send every notification.
