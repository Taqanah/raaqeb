تنشر قناة Teams كل إشعار في قناة أو محادثة في Microsoft Teams بطاقةً من نوع Adaptive Card، عبر Webhook لسير عمل في تطبيق Workflows. نص البطاقة بلغة القناة، ويتلوّن عنوانها بحسب الحدث، وفيها أزرار تفتح المراقبة.

تتجه Microsoft إلى إيقاف موصّلات Microsoft 365، وهي Webhooks الواردة القديمة في Teams، وبديلها Workflows (وهو Power Automate). ينشر راقب إلى رابط Webhook لسير عمل، لا إلى موصّل.

## ما تحتاجه أولًا

سير عمل يبدأ حين يصل طلب Webhook إلى Teams. في Teams:

1. افتح الفريق والقناة (أو المحادثة) التي تريد وصول التنبيهات إليها.
2. اضغط **More options** (النقاط الثلاث) بجانب القناة، ثم **Workflows**.
3. اختر القالب **Send webhook alerts to a channel**، أو ابدأ من الصفر بخطوة أولى هي **When a Teams webhook request is received** تليها خطوة تنشر البطاقة في القناة أو المحادثة.
4. سمِّه واختر مكان النشر واحفظ.
5. انسخ رابط Webhook الذي يعرضه سير العمل.

يحمل الرابط توقيع سير العمل، فاحفظه سرًّا. وسير العمل يتبع من أنشأه وينشر باسمه أو باسم بوت التدفق: إن غادر المؤسسة فأضف مالكًا مشاركًا أولًا وإلا توقف سير العمل.

## الحقول

| الحقل | المعنى | مطلوب | الافتراضي |
| --- | --- | --- | --- |
| **الاسم** | اسم القناة في لوحة الإدارة، 80 حرفًا على الأكثر. | نعم | لا يوجد |
| **لغة القناة** | لغة البطاقة. | لا | **لغة التثبيت** |
| **تطبيق على المراقبات الجديدة تلقائيًا** | تبدأ كل مراقبة جديدة وهذه القناة محددة فيها. | لا | مفعّل |
| **عنوان الرابط** | رابط Webhook لسير العمل. يحمل الرابط توقيعًا، فهو من البيانات السرية: يُحفظ مُعمّى بمفتاح راقب ولا يُعرض بعد الحفظ. يُقبل أي عنوان `http` أو `https`. | نعم | لا يوجد |

## الرسالة

يرسل راقب محتوى JSON هذا إلى الرابط، وهو هنا لإشعار تعطّل:

```json
{
  "type": "message",
  "attachments": [
    {
      "contentType": "application/vnd.microsoft.card.adaptive",
      "contentUrl": null,
      "content": {
        "$schema": "http://adaptivecards.io/schemas/adaptive-card.json",
        "type": "AdaptiveCard",
        "version": "1.5",
        "msteams": { "width": "Full" },
        "rtl": true,
        "body": [
          { "type": "TextBlock", "text": "الموقع الرئيسي: متعطّل", "wrap": true, "size": "Medium", "weight": "Bolder", "color": "Attention" },
          { "type": "TextBlock", "text": "المراقبة متعطّلة.", "wrap": true },
          { "type": "TextBlock", "text": "المراقبة: الموقع الرئيسي", "wrap": true, "spacing": "None" },
          { "type": "TextBlock", "text": "الهدف: https://example.com", "wrap": true, "spacing": "None" },
          { "type": "TextBlock", "text": "العلة: انتهت مهلة الانتظار", "wrap": true, "spacing": "None" },
          { "type": "TextBlock", "text": "الوقت: 25 سبتمبر 2026، 18:49 (UTC)", "wrap": true, "spacing": "None" }
        ],
        "actions": [
          { "type": "Action.OpenUrl", "title": "فتح المراقبة", "url": "https://status.example.com/admin/monitors/0199a3c2-5f1e-7c3a-9b1d-2f6e8a4c1b7d" },
          { "type": "Action.OpenUrl", "title": "فتح حادثة", "url": "https://status.example.com/admin/incidents/new?monitor=0199a3c2-5f1e-7c3a-9b1d-2f6e8a4c1b7d" }
        ]
      }
    }
  ]
}
```

- **العنوان**: عنوان الرسالة، مثل `الموقع الرئيسي: متعطّل`. ولونه `Attention` للتعطّل وتذكيره، و`Good` للتعافي وانتهاء التعثّر، و`Warning` لبدء التعثّر واقتراب انتهاء الشهادة أو تسجيل النطاق. ولا لون للرسالة التجريبية.
- **الأسطر**: الجملة، ثم كتلة نص لكل سطر من أسطر الاسم والقيمة. انظر [ما يقوله الإشعار](/docs/notifications#what-a-notification-says).
- **الأزرار**: «فتح المراقبة»، وفي إشعار التعطّل «فتح حادثة» أيضًا. يلزمهما عنوان عام محفوظ، وبدونه يُتركان.
- **الاتجاه**: تضع البطاقة العربية `"rtl": true`، فتُقرأ من اليمين إلى اليسار.
- **Markdown**: يقرأ Teams تنسيق Markdown في كتلة النص. يضيف راقب شرطة مائلة عكسية قبل `\` و`*` و`_` و`~` و`` ` `` و`|` و`<` و`>` و`#` و`[` و`]` خارج الروابط، فيظهر اسم المراقبة كما كُتب ولا يستطيع أن يصنع رابطًا أو إشارة أو تنسيقًا.

وإن بنيت سير العمل من الصفر فيجب أن تنشر خطوة النشر فيه البطاقة الموجودة في `attachments`.

## حالات الفشل والحدود

يقبل Teams رسالة حجمها 28 كيلوبايت على الأكثر، ويقيّد Webhook حين تزيد طلباته على أربعة في الثانية. تنتهي مهلة المحاولة الواحدة بعد 10 ثوانٍ، وتُعاد المحاولة الفاشلة بعد 30 ثانية، ثم دقيقتين، ثم 10 دقائق. وإن أجاب التقييد برمز `429` أُعيدت المحاولة وفق الجدول نفسه.

| رمز العلة | النص | السبب المعتاد |
| --- | --- | --- |
| `unexpected_status` | رمز حالة غير متوقع | رفض Workflows المنشور. يعرض **المرصود** رمز الحالة و**نص الخطأ** الإجابة، مثلًا حين يكون سير العمل معطّلًا أو محذوفًا، أو نُسخ الرابط خطأً. |
| `timeout` | انتهت مهلة الانتظار | لم تصل إجابة خلال 10 ثوانٍ. |
| `dns_failed` | تعذّر العثور على عنوان المضيف | لم يُعثر على عنوان لمضيف الرابط. |
| `connection_refused` | رُفض الاتصال | لا شيء يستمع على مضيف الرابط ومنفذه. |
| `connection_failed` | تعذّر الاتصال | قُطع الاتصال أو تعذّر الوصول إلى المضيف. |
| `certificate_expired` | انتهت صلاحية الشهادة | انتهت صلاحية شهادة المستقبل. |
| `certificate_invalid` | الشهادة غير صالحة | يتعذّر التحقق من الشهادة. |
| `unknown` | خطأ غير معروف | أي شيء آخر. يذكر **نص الخطأ** ما حدث. |

النجاح يعني أن Workflows قبل الطلب. أما نشر خطوات سير العمل في Teams بعد ذلك فيظهر في سجل تشغيل سير العمل في Teams، لا في راقب. ويُحذف رابط Webhook من كل نص خطأ مسجّل.
