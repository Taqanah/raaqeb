تنشر قناة Google Chat كل إشعار في مساحة واحدة في Google Chat عبر Webhook الوارد للمساحة، بطاقةً بلغة القناة: عنوان الرسالة عنوانًا للبطاقة، وتحته النص، وأزرار تفتح المراقبة. ويوضع النص نفسه في النص البديل للرسالة، وهو ما يعرضه الهاتف في إشعاره.

## ما تحتاجه أولًا

رابط Webhook وارد للمساحة. في Google Chat:

1. افتح المساحة واضغط اسمها في الأعلى، ثم **Apps & integrations**.
2. اضغط **Manage webhooks**، ثم **Add webhook**.
3. سمِّه، مثل `Raaqeb`، واحفظ.
4. انسخ رابط Webhook. يبدأ الرابط بـ `https://chat.googleapis.com/v1/spaces/`.

وقد يعطّل مسؤول Google Workspace الـ Webhooks في المؤسسة؛ فإن غاب الخيار فاسأله.

## الحقول

| الحقل | المعنى | مطلوب | الافتراضي |
| --- | --- | --- | --- |
| **الاسم** | اسم القناة في لوحة الإدارة، 80 حرفًا على الأكثر. | نعم | لا يوجد |
| **لغة القناة** | لغة البطاقة. | لا | **لغة التثبيت** |
| **تطبيق على المراقبات الجديدة تلقائيًا** | تبدأ كل مراقبة جديدة وهذه القناة محددة فيها. | لا | مفعّل |
| **عنوان الرابط** | رابط Webhook الوارد للمساحة. يحمل الرابط مفتاحًا ورمزًا، فهو من البيانات السرية: يُحفظ مُعمّى بمفتاح راقب ولا يُعرض بعد الحفظ. | نعم | لا يوجد |

## الرسالة

يرسل راقب محتوى JSON هذا إلى رابط Webhook، وهو هنا لإشعار تعطّل:

```json
{
  "cardsV2": [
    {
      "card": {
        "header": { "title": "الموقع الرئيسي: متعطّل" },
        "sections": [
          {
            "widgets": [
              {
                "textParagraph": {
                  "text": "المراقبة متعطّلة.<br><br>المراقبة: الموقع الرئيسي<br>الهدف: https://example.com<br>العلة: انتهت مهلة الانتظار<br>الوقت: 25 سبتمبر 2026، 18:49 (UTC)"
                }
              },
              {
                "buttonList": {
                  "buttons": [
                    { "text": "فتح المراقبة", "onClick": { "openLink": { "url": "https://status.example.com/admin/monitors/0199a3c2-5f1e-7c3a-9b1d-2f6e8a4c1b7d" } } },
                    { "text": "فتح حادثة", "onClick": { "openLink": { "url": "https://status.example.com/admin/incidents/new?monitor=0199a3c2-5f1e-7c3a-9b1d-2f6e8a4c1b7d" } } }
                  ]
                }
              }
            ]
          }
        ]
      }
    }
  ],
  "fallbackText": "الموقع الرئيسي: متعطّل\n\nالمراقبة متعطّلة.\n\nالمراقبة: الموقع الرئيسي\nالهدف: https://example.com\nالعلة: انتهت مهلة الانتظار\nالوقت: 25 سبتمبر 2026، 18:49 (UTC)\nالرابط: https://status.example.com/admin/monitors/0199a3c2-5f1e-7c3a-9b1d-2f6e8a4c1b7d\nفتح حادثة: https://status.example.com/admin/incidents/new?monitor=0199a3c2-5f1e-7c3a-9b1d-2f6e8a4c1b7d"
}
```

- **العنوان**: عنوان الرسالة، مثل `الموقع الرئيسي: متعطّل`.
- **الفقرة**: الجملة، ثم أسطر الاسم والقيمة. فقرة البطاقة HTML، فيكتب راقب فيها `&` و`<` و`>` على هيئة كيانات HTML، فلا يستطيع الاسم أن يصنع وسمًا أو رابطًا. انظر [ما يقوله الإشعار](/docs/notifications#what-a-notification-says).
- **الأزرار**: «فتح المراقبة»، وفي إشعار التعطّل «فتح حادثة» أيضًا. يلزمهما عنوان عام محفوظ، وبدونه يُتركان.
- **النص البديل**: العنوان ونص الفقرة وسطر لكل رابط، بنص عادي.

## حالات الفشل والحدود

يقبل Google Chat طلبًا واحدًا في الثانية لكل مساحة، تتشاركه كل Webhooks فيها، وبطاقة لا تزيد على 32 كيلوبايت. تنتهي مهلة المحاولة الواحدة بعد 10 ثوانٍ، وتُعاد المحاولة الفاشلة بعد 30 ثانية، ثم دقيقتين، ثم 10 دقائق. وإن أجاب التقييد برمز `429` أُعيدت المحاولة وفق الجدول نفسه.

| رمز العلة | النص | السبب المعتاد |
| --- | --- | --- |
| `unexpected_status` | رمز حالة غير متوقع | رفض Google Chat المنشور. يعرض **المرصود** رمز الحالة و**نص الخطأ** إجابة Google، مثلًا حين حُذف Webhook، أو نُسخ مفتاحه أو رمزه خطأً، أو رُفضت البطاقة. |
| `timeout` | انتهت مهلة الانتظار | لم تصل إجابة خلال 10 ثوانٍ. |
| `dns_failed` | تعذّر العثور على عنوان المضيف | لم يُعثر على عنوان لمضيف الرابط. |
| `connection_refused` | رُفض الاتصال | لا شيء يستمع على مضيف الرابط ومنفذه. |
| `connection_failed` | تعذّر الاتصال | قُطع الاتصال أو تعذّر الوصول إلى المضيف. |
| `certificate_expired` | انتهت صلاحية الشهادة | انتهت صلاحية شهادة المستقبل. |
| `certificate_invalid` | الشهادة غير صالحة | يتعذّر التحقق من الشهادة. |
| `unknown` | خطأ غير معروف | أي شيء آخر. يذكر **نص الخطأ** ما حدث. |

يُحذف رابط Webhook من كل نص خطأ مسجّل.
