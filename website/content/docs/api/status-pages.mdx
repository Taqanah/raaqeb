تجيب صفحة الحالة المنشورة عن هذه الطلبات لأي أحد. أما غير المنشورة فتجيب بـ `404`، إلا للمشغّل الذي سجّل الدخول، فيحصل على مستنداتها مع `Cache-Control: no-store`.

تحمل كل إجابة ترويسة ETag. أعِدها في `If-None-Match`، فتأتي الإجابة التي لم تتغير `304` بلا محتوى. و`{id}` هو معرّف صفحة الحالة.
