A published status page answers these to anyone. One that is not published answers `404`, except to the signed-in operator, who gets its documents with `Cache-Control: no-store`.

Each answer carries an ETag. Send it back in `If-None-Match` and an unchanged answer is a `304` with no body. `{id}` is the status page's id.
