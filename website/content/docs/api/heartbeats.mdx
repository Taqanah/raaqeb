تنتظر مراقبة النبض نبضة واحدة في كل مدة. فإن لم تصل خلال المدة وفترة السماح، صار فحصها متعطّلًا بعلة «تأخرت النبضة». وإذا فشلت المهمة فبوسعها أن تُبلغ بذلك، فيتعطّل الفحص فورًا بعلة «أبلغت المهمة عن فشلها». لكل مراقبة نبض رابطها الخاص وفيه رمز، ويظهر في لوحة **رابط النبض** بعد حفظها، وتشرح صفحة [مراقبات النبض](/docs/monitors/heartbeat) طريقة إعدادها. استدعِ الرابط في نهاية مهمتك بأي طريقة أسهل عليك:

```sh
curl -fsS https://status.example.com/api/heartbeat/<token>
```

وللإبلاغ عن فشل، أضف `/fail` بعد الرمز، مع رمز خروج ورسالة قصيرة إن شئت:

```sh
curl -fsS "https://status.example.com/api/heartbeat/<token>/fail?exit=2&message=disk%20full"
```

الرمز هو بيانات الاستيثاق الوحيدة، ومن يملكه يستطيع تسجيل نبضات للمراقبة.
