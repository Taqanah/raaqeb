تنتظر مراقبة النبض نبضة واحدة في كل مدة. فإن لم تصل خلال المدة وفترة السماح، صار فحصها متعطّلًا بعلة «تأخرت النبضة». لكل مراقبة نبض رابطها الخاص وفيه رمز، ويظهر في لوحة **رابط النبض** بعد حفظها، وتشرح صفحة [مراقبات النبض](/docs/monitors/heartbeat) طريقة إعدادها. استدعِ الرابط في نهاية مهمتك بأي طريقة أسهل عليك:

```sh
curl -fsS https://status.example.com/api/heartbeat/<token>
```

الرمز هو بيانات الاستيثاق الوحيدة، ومن يملكه يستطيع تسجيل نبضات للمراقبة.
