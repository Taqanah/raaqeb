---
title: لمساعدات الذكاء الاصطناعي
description: التوثيقات بصيغة Markdown لمساعد ذكاء اصطناعي يقرؤها، في ملف llms.txt وملف llms-full.txt ونسخة Markdown من كل صفحة.
---

يقرأ مساعد الذكاء الاصطناعي نص Markdown أيسر مما يقرأ صفحات الموقع، فيقدّم الموقع التوثيقات بصيغة Markdown في ثلاثة أشكال:

| العنوان | ما فيه |
| --- | --- |
| `/llms.txt` | فهرس التوثيقات بصيغة [llmstxt.org](https://llmstxt.org): عنوان كل صفحة ورابطها ووصفها، بالعربية ثم بالإنجليزية. |
| `/llms-full.txt` | نص كل صفحات التوثيقات في ملف واحد، بالعربية ثم بالإنجليزية. |
| `<page>.md` | نسخة Markdown من صفحة واحدة: أضف `.md` إلى عنوانها، مثل `/docs/get-started.md`. |

وينسخ زر **نسخ Markdown** تحت عنوان كل صفحة النص نفسه، لتلصقه في محادثة.

أعطِ المساعد الفهرس ليختار الصفحات التي يحتاجها، أو الملف الكامل إن كان يتسع له:

```sh
curl https://raaqeb.dev/llms.txt
```

أما واجهة التثبيت البرمجية، فكل تثبيت يقدّم مستند OpenAPI على `GET /api/openapi.json`؛ انظر [الواجهة البرمجية](/docs/api).
