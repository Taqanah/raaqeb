تتصل مراقبة قاعدة البيانات بخادوم Postgres أو MySQL أو Redis عبر رابط الاتصال، وتسجّل الدخول، وتنفّذ `SELECT 1` أو `PING` أو استعلامك أنت، ثم تغلق الاتصال. وإذا حددت قيمة متوقعة، وجب أن تساويها القيمة الأولى في الإجابة. استخدمها حين لا يكفي أن يقبل الخادوم الاتصالات: فرفض تسجيل الدخول، وغياب قاعدة البيانات، وفشل الاستعلام تظهر كلها تعطّلًا.

## إضافة مراقبة قاعدة بيانات

اضغط **إضافة مراقبة**، ثم اختر **قاعدة بيانات** في **نوع الفحص**، ثم اختر **نوع قاعدة البيانات**: **Postgres** أو **MySQL** أو **Redis**. الحقول المشتركة بين كل أنواع الفحص في صفحة [المراقبات](/docs/monitors).

| الحقل | معناه | الافتراضي والحدود |
|---|---|---|
| **نوع قاعدة البيانات** | الخادوم الذي يصل إليه الرابط. | Postgres. |
| **رابط الاتصال** | عنوان الخادوم مع المستخدم وكلمة المرور، مثل `postgres://user:password@db.example.com:5432/app`. | مطلوب، حتى 2048 حرفًا. يجب أن يسمّي مضيفًا. انظر البروتوكولات أدناه. |
| **الاستعلام** (Postgres وMySQL) أو **الأمر** (Redis) | ما ينفّذه كل فحص. | فارغ، أي ينفّذ `SELECT 1`، أو `PING` في Redis. حتى 4000 حرف. |
| **القيمة المتوقعة** | نص يجب أن تساويه القيمة الأولى في الإجابة. | فارغة، أي تُقبل أي إجابة. حتى 200 حرف. |

يجب أن يبدأ رابط الاتصال بأحد بروتوكولات نوعه:

| نوع قاعدة البيانات | البروتوكولات | المنفذ إذا لم يسمّ الرابط منفذًا |
|---|---|---|
| Postgres | `postgres://`، `postgresql://` | `5432` |
| MySQL | `mysql://`، `mariadb://` | `3306` |
| Redis | `redis://`، و`rediss://` لـTLS | `6379` |

لا يكون مسار رابط Redis إلا رقم قاعدة بيانات، مثل `/0`.

يحمل رابط الاتصال كلمة المرور، فهو من بيانات الاستيثاق: يحفظه راقب مُعمّى بمفتاح راقب ولا يعرضه مرة أخرى. وعند التعديل، اترك الحقل فارغًا لتُبقي على الرابط المحفوظ. ولا ينسخه **إنشاء نسخة**. وتعرض قائمة المراقبات مضيف الرابط ومنفذه فقط.

<Callout type="warn">
ينفّذ راقب الاستعلام كما كتبته، في كل فحص. اجعله للقراءة فقط، وسجّل الدخول بمستخدم لا يملك إلا القراءة.
</Callout>

### الاستعلام والقيمة المتوقعة

في Postgres وMySQL، القيمة الأولى هي العمود الأول من الصف الأول، والاستعلام الذي لا يعيد صفًا يجيب بنص فارغ. وفي Redis، يُقسَّم الأمر ووسيطاته عند المسافات، فلا تحتوي الوسيطة مسافة، والقيمة الأولى هي الإجابة.

تُقارن الإجابة نصًا: السلسلة النصية كما هي، والتاريخ بصيغة ISO 8601، والعدد والقيمة المنطقية بصيغة JSON (`1`، `true`، `false`)، وأي شيء آخر بصيغة JSON. ويعرض **الفحص الفوري** الإجابة، فشغّله مرة لترى النص الذي تتوقعه بالضبط.

### MySQL 8

مع طريقة تسجيل الدخول الافتراضية في MySQL 8، لا يسجّل راقب الدخول إلا عبر اتصال مُعمّى. أضف `?sslmode=require` إلى الرابط، مثل `mysql://user:password@db.example.com:3306/app?sslmode=require`. وبدونه يتعطّل الفحص بعلة «لا يقبل الخادوم تسجيل الدخول إلا عبر اتصال معمّى، فأضف ⁦?sslmode=require⁩ إلى رابط الاتصال».

## يعمل ومتعثّر ومتعطّل

يفتح كل فحص اتصالًا جديدًا. تمتد مدة الاستجابة من بدء الاتصال إلى وصول الإجابة، ولا تتجاوز مهلة الانتظار، ويغطي مؤقّت واحد الاتصال وتسجيل الدخول والاستعلام. وإذا بقي الاستعلام يعمل عند انتهاء مهلة الانتظار، أُمهل ثانية واحدة لينتهي قبل أن يُغلق الاتصال.

- **يعمل**: سجّل الخادوم الدخول وأجاب، والقيمة الأولى تساوي القيمة المتوقعة إن حُددت.
- **متعثّر**: كما في يعمل، لكن أبطأ من حد التعثّر.
- **متعطّل**: فشلت خطوة ما، أو لم تطابق الإجابة، في المحاولة الأخيرة.

العلل التي يذكرها الفحص المتعطّل:

| العلة | ما حدث |
|---|---|
| انتهت مهلة الانتظار | استغرق الاتصال وتسجيل الدخول والاستعلام معًا أكثر من مهلة الانتظار. |
| رُفض الاتصال | لم يقبل شيء الاتصال. تعرض مضيف الرابط ومنفذه. وفي Postgres وMySQL، تُذكر هذه العلة أيضًا لاسم مضيف لا يُعثر له على عنوان. |
| تعذّر الاتصال | تخلّى برنامج التشغيل عن الاتصال. ويُحفظ الرمز. وفي Redis، تُذكر هذه العلة للمنفذ الذي يرفض الاتصال وللمضيف الذي لا يُعثر له على عنوان. |
| رفض الخادوم تسجيل الدخول | المستخدم أو كلمة المرور خطأ، أو قاعدة البيانات غير موجودة. تعرض رمز الخادوم، مثل `28P01` أو `1045`. |
| رفض الخادوم الاستعلام | سجّل الخادوم الدخول ثم أعاد خطأً للاستعلام. تعرض رمزه، مثل `42703` أو `1054`. |
| لا يقبل الخادوم تسجيل الدخول إلا عبر اتصال معمّى، فأضف ⁦?sslmode=require⁩ إلى رابط الاتصال | MySQL 8، انظر أعلاه. |
| الشهادة غير صالحة | لم تجتز شهادة TLS للخادوم التحقق. |
| لم يتحقق معيار | القيمة الأولى لا تساوي القيمة المتوقعة. تعرض كلتيهما، حتى 200 حرف، مع حجب الرابط وكلمة المرور. |
| خطأ غير معروف | أي شيء آخر، ومنه رابط محفوظ لم يعد مفتاح راقب يفكّ تعميته. ويُحفظ نص الخطأ الخام بجانبه، مع حجب الرابط وكلمة المرور. |

## مثال

لتتأكد أن خادوم Postgres الأساسي لم يصبح نسخة متماثلة، اضبط **نوع قاعدة البيانات** على Postgres، و**رابط الاتصال** على `postgres://monitor:secret@db.example.com:5432/app`، و**الاستعلام** على `SELECT pg_is_in_recovery()`، و**القيمة المتوقعة** على `false`.

إذا جعل تجاوز الفشل هذا الخادوم نسخة متماثلة، تعطّل الفحص بعلة «لم يتحقق معيار»، والمتوقع `false`، والمرصود `true`. وإذا غيّر أحد كلمة مرور المستخدم `monitor`، تعطّل بعلة «رفض الخادوم تسجيل الدخول» والرمز `28P01`.

وفي Redis، يجيب `PING` الافتراضي بـ`PONG`. ولتفحص مفتاحًا بدلًا منه، اضبط **الأمر** على `GET maintenance:flag` و**القيمة المتوقعة** على `off`.
