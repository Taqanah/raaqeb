تسأل مراقبة الحاوية الواجهة البرمجية لـDocker Engine عن حاوية واحدة باسمها. تعمل الحاوية ما دامت قيد التشغيل ولم يحكم عليها فحص الصحة فيها، إن كان لها فحص صحة، بأنها معتلّة. استخدمها للخدمات التي تعمل في حاويات على مضيف يصل إليه راقب، ومنها خدمات ليس لها منفذ يُفحص من الخارج. وتعمل أيضًا الواجهة البرمجية لـPodman المتوافقة مع Docker.

لا يفعل راقب إلا القراءة: يرسل كل فحص `GET /containers/<name>/json`، وترسل قائمة الحاويات في النموذج `GET /containers/json`. وتشرح صفحة [مراقبات الحاويات](/docs/operate/container-monitors) كيف تمنح راقب الوصول إلى Docker، ويُفضَّل أن يكون عبر وكيل مقبس لا يمرّر إلا هذين المسارين.

## إضافة مراقبة حاوية

اضغط **إضافة مراقبة**، ثم اختر **Docker** في **نوع الفحص**. الحقول المشتركة بين كل أنواع الفحص في صفحة [المراقبات](/docs/monitors).

| الحقل | معناه | الافتراضي والحدود |
|---|---|---|
| **عنوان Docker** | المسار المطلق لمقبس Unix، أو رابط `http` أو `https` لواجهة Docker Engine البرمجية، مثل رابط وكيل المقبس. | `/var/run/docker.sock`. حتى 2048 حرفًا. يُرفض الرابط الذي فيه اسم مستخدم أو كلمة مرور أو استعلام أو جزء رابط. |
| **اسم الحاوية** | الحاوية التي تُفحص. | مطلوب، حتى 255 حرفًا، ويُكتب كما يكتب Docker الأسماء: حرف أو رقم، ثم أحرف أو أرقام أو `_` أو `.` أو `-`، دون شرطة مائلة في أوله. |

اضغط **اعرض حاويات Docker** لتقرأ كل حاوية يعرفها العنوان، والمتوقفة منها أيضًا، مع حالتها وصورتها، ثم اختر واحدة ليُملأ اسمها. وإذا فشلت القائمة، عرض النموذج العلة التي سيذكرها الفحص، فاكتب الاسم بنفسك.

يتبع راقب الاسم لا معرّف الحاوية، فتبقى المراقبة تعمل حين يُعاد إنشاء الحاوية، كما يفعل Docker Compose. ولا يحمل العنوان بيانات استيثاق، ويُحفظ غير مُعمّى.

## يعمل ومتعثّر ومتعطّل

مدة الاستجابة هي الزمن الذي استغرقه استدعاء الواجهة البرمجية، ولا تتجاوز مهلة الانتظار.

- **يعمل**: الحاوية قيد التشغيل، وفحص الصحة فيها سليم أو ما زال في بدايته أو غير موجود.
- **متعثّر**: كما في يعمل، لكن استدعاء الواجهة البرمجية أبطأ من حد التعثّر.
- **متعطّل**: الحاوية غير موجودة، أو لا تعمل، أو يُعاد تشغيلها، أو موقوفة مؤقتًا، أو معطوبة، أو معتلّة، أو تعذّر سؤال Docker، في المحاولة الأخيرة.

العلل التي يذكرها الفحص المتعطّل:

| العلة | ما حدث |
|---|---|
| لا توجد حاوية بهذا الاسم | لا يعرف Docker حاوية بهذا الاسم. |
| الحاوية لا تعمل | الحاوية متوقفة. تعرض حالتها في Docker، مثل `exited` أو `created`، وآخر رمز خروج. |
| يعيد Docker تشغيل الحاوية | تعيد سياسة إعادة التشغيل تشغيلها. تعرض رمز الخروج للتشغيل الذي انتهى. |
| الحاوية موقوفة مؤقتًا | أُوقفت مؤقتًا بالأمر `docker pause`. |
| الحاوية معطوبة | لم يستطع Docker إيقافها أو حذفها. |
| يقول Docker إنّ الحاوية معتلّة | الحاوية تعمل، ويقول `HEALTHCHECK` فيها إنها معتلّة. ويُحفظ آخر خرج لفحص الصحة نصًا للخطأ. |
| رمز حالة غير متوقع | أجاب العنوان برمز حالة غير `200`، مثل `403` أو `405` من وكيل المقبس. |
| تعذّر الاتصال | لم يُفتح المقبس: `ENOENT` حين لا يوجد شيء في المسار، و`EACCES` حين لا يُسمح لراقب بفتحه، و`ECONNREFUSED` حين لا يستمع شيء. وعبر رابط، أُعيد ضبط الاتصال أو تعذّر الوصول. |
| رُفض الاتصال، تعذّر العثور على عنوان المضيف | عبر رابط، كما في مراقبة [HTTP](/docs/monitors/http). |
| انتهت مهلة الانتظار | لم يُجب Docker خلال مهلة الانتظار. |
| خطأ غير معروف | أي شيء آخر، مثل إجابة لا تصف حاوية. ويُحفظ النص الخام بجانبه. |

## مثال

في مشروع Compose حاوية اسمها `web` لها `HEALTHCHECK`، ووكيل مقبس كما في [مراقبات الحاويات](/docs/operate/container-monitors). اضبط **عنوان Docker** على `http://socket-proxy:2375` و**اسم الحاوية** على `web`.

- ما دامت `web` في بدايتها، يقول فحص الصحة إنها تبدأ، فيعمل الفحص.
- إذا استنفد فحص الصحة محاولاته فاشلًا، تعطّل الفحص بعلة «يقول Docker إنّ الحاوية معتلّة»، وحمل نص الخطأ آخر خرج لفحص الصحة.
- إذا انهارت `web` برمز الخروج `137` وأعادتها سياسة إعادة التشغيل، فالفحص الذي يقع بين الأمرين يتعطّل بعلة «يعيد Docker تشغيل الحاوية» مع رمز الخروج.
