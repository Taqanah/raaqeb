ترسل مراقبة HTTP طلبًا إلى عنوان رابط، وتحكم على الاستجابة بمعايير النجاح: قائمة مرتبة من المعايير يجب أن تتحقق كلها. استخدمها للمواقع والواجهات البرمجية وعناوين الصحة. وللمنفذ الذي يتكلم ميفاقًا غير HTTP، استخدم [TCP](/docs/monitors/tcp).

## إضافة مراقبة HTTP

اضغط **إضافة مراقبة**، ثم اختر **HTTP** في **نوع الفحص**، واملأ الأقسام التالية. الحقول المشتركة بين كل أنواع الفحص (الاسم والجدولة والتنظيم والاحتفاظ والإشعارات) في صفحة [المراقبات](/docs/monitors).

### المراقبة

| الحقل | معناه | الافتراضي والحدود |
|---|---|---|
| **الطريقة** | طريقة الطلب. | `GET`. ومعها `HEAD` و`POST` و`PUT` و`PATCH` و`DELETE` و`OPTIONS`. |
| **عنوان الرابط** | العنوان المطلوب. | مطلوب. يبدأ بـ`http://` أو `https://`. يقبل عنوان IP و`localhost`. ويُرفض اسم المستخدم أو كلمة المرور داخل الرابط: استخدم **الاستيثاق**. |

### معايير النجاح

يعمل الفحص حين تتحقق كل المعايير بالترتيب. أول معيار يفشل ينهي الفحص ويعطيه علته، ولا تُقيَّم المعايير التي بعده. اضغط **إضافة معيار** لصف آخر. تحتاج القاعدة معيارًا واحدًا على الأقل، وتبدأ المراقبة الجديدة بمعيار **رمز الحالة ضمن** `2xx`.

| المعيار | الحقول | يتحقق حين |
|---|---|---|
| **رمز الحالة ضمن** | **رموز الحالة** | يكون رمز الحالة في القائمة. كل عنصر فئة (`2xx`) أو رمز (`204`) أو نطاق رموز (`200-299`)، تفصل بينها فواصل. |
| **المحتوى يتضمن** | **النص** | يتضمن المحتوى النص، والمقارنة حساسة لحالة الأحرف. |
| **المحتوى لا يتضمن** | **النص** | لا يتضمن المحتوى النص. |
| **قيمة JSON تساوي** | **المسار، مثل ⁦data.status⁩**، **القيمة** | المحتوى JSON، والمسار موجود، وقيمته نصًا تساوي **القيمة**. |
| **قيمة JSON تطابق النمط** | **المسار، مثل ⁦data.status⁩**، **النمط** | المحتوى JSON، والمسار موجود، وقيمته نصًا تطابق التعبير النمطي. |
| **الترويسة تساوي** | **اسم الترويسة**، **القيمة** | في الاستجابة هذه الترويسة، وقيمتها تساوي **القيمة** تمامًا. وإذا غابت الترويسة فشل المعيار، حتى أمام قيمة فارغة. |
| **مدة الاستجابة أقل من** | **الزمن** (ملّي ثانية) | مدة الاستجابة أقل من هذا العدد من الملّي ثواني، من 1 إلى 60000. |

مسار JSON مفاتيح تفصل بينها نقاط، والفهارس بين أقواس مربعة: `status`، `data.items[0].status`. لا تُدعم حروف البدل ولا تعابير التصفية ولا الشرائح. تُقارن قيمة السلسلة النصية كما هي، وتُقارن أي قيمة أخرى بنصها في JSON، فيُقرأ العدد `12`، والقيمة المنطقية `true`، والكائن `{"a":1}`. النمط تعبير نمطي من JavaScript بلا خيارات، فأضف `^` و`$` لتطابق القيمة كلها.

يقرأ راقب ميغابايت واحدًا من المحتوى على الأكثر ويلغي الباقي، وتُطبَّق المعايير على ما قُرئ بعد فكّ ترميزه بـUTF-8.

### الطلب

| الحقل | معناه | الافتراضي والحدود |
|---|---|---|
| **محتوى الطلب** | يُرسل مع الطلب. لا يرسل `GET` و`HEAD` محتوى. | فارغ. حتى 65536 حرفًا. |
| **تتبّع إعادة التوجيه** | يتبع استجابات `301` و`302` و`303` و`307` و`308` إلى ترويسة `Location`. وإذا عطّلته، حُكم على استجابة إعادة التوجيه نفسها. | مفعّل. 10 إعادات توجيه على الأكثر. |
| **تجاهل أخطاء TLS** | يقبل الشهادات المنتهية الصلاحية والموقّعة ذاتيًا. | غير مفعّل. |
| **الاستيثاق** | **بلا استيثاق**، أو **اسم مستخدم وكلمة مرور** (الاستيثاق الأساسي)، أو **رمز Bearer**. | بلا استيثاق. لا يحتوي اسم المستخدم نقطتين رأسيتين. |
| **ترويسات الطلب** | ترويسات مخصصة تُرسل مع كل محاولة. اضغط **إضافة ترويسة** لترويسة أخرى. | حتى 20، ولا يتكرر اسم. القيمة سطر واحد من الأحرف اللاتينية. |

الاستيثاق وترويسات الطلب بيانات استيثاق: يحفظها راقب مُعمّاة بمفتاح راقب ولا يعرض قيمها مرة أخرى. وعند التعديل، تعرض البيانات السرية المحفوظة «محفوظة؛ اتركها فارغة للإبقاء عليها». وإذا غيّرت اسم ترويسة فاكتب قيمتها من جديد. وإذا ضبطت **الاستيثاق** وترويسة `Authorization` مخصصة معًا، غلب **الاستيثاق**.

عند تتبّع إعادة التوجيه، تُحذف ترويسات `Authorization` و`Cookie` و`Proxy-Authorization` إذا انتقل الطلب إلى مصدر آخر، وتبقى الترويسات الأخرى. ويحوّل `303`، أو `301` أو `302` جوابًا عن `POST`، الطلب التالي إلى `GET` بلا محتوى. وتفشل المحاولة إذا أعيد توجيهها إلى بروتوكول غير `http` و`https`.

### الشهادة وحفظ الاستجابة

| الحقل | معناه | الافتراضي والحدود |
|---|---|---|
| **نبّه قبل انتهاء الشهادة** | يسجّل شهادة الموقع ويرسل حدث قرب انتهاء الشهادة. انظر [بيانات الشهادة](/docs/monitors/certificates). | غير مفعّل. لعناوين `https` فقط. |
| **قبل الانتهاء** | قبل كم يومًا من انتهاء الصلاحية يُرسل التحذير الأول. | 14 يومًا. من 1 إلى 365. |
| **حفظ الاستجابة** | متى يحفظ الفحص ترويسات الاستجابة وأول 4 كيلوبايت من المحتوى: **معطّل**، أو **عند التعطّل فقط** (للفحوص المتعطّلة)، أو **دائمًا**. | معطّل. يكلّف **دائمًا** نحو 5.8 ميغابايت في اليوم بفاصل زمني دقيقة واحدة. |

لا تحمل الاستجابة المحفوظة ترويسات الطلب ولا بيانات الاستيثاق أبدًا. تبقى أسماء `Set-Cookie` وكل ترويسة استجابة يتضمن اسمها `auth` أو `token` أو `key` أو `cookie`، وتُحذف قيمها. وإذا كررت الاستجابة أي بيانات استيثاق أرسلها الفحص، حلّ محلها `[REDACTED]`. ولا تُعدّ قيم ترويسات الطلب القياسية `Accept` و`Accept-Encoding` و`Accept-Language` و`Content-Type` و`Cache-Control` و`User-Agent` بيانات استيثاق.

## يعمل ومتعثّر ومتعطّل

تمتد مدة الاستجابة من بداية الطلب إلى نهاية قراءة المحتوى، ولا تتجاوز مهلة الانتظار.

- **يعمل**: تحققت كل المعايير، ومدة الاستجابة ضمن حد التعثّر.
- **متعثّر**: تحققت كل المعايير، ومدة الاستجابة فوق حد التعثّر.
- **متعطّل**: فشل معيار، أو لم يكتمل الطلب، في المحاولة الأخيرة.

العلل التي يذكرها الفحص المتعطّل:

| العلة | ما حدث |
|---|---|
| انتهت مهلة الانتظار | استغرقت المحاولة، مع قراءة المحتوى، أكثر من مهلة الانتظار. |
| تعذّر العثور على عنوان المضيف | لم يُعثر على عنوان لاسم المضيف. |
| رُفض الاتصال | لم يقبل شيء الاتصال على المضيف والمنفذ. |
| تعذّر الاتصال | أُعيد ضبط الاتصال أو أُغلق أو تعذّر الوصول إليه، أو انتهت مصافحة TLS قبل أي شهادة. ويُحفظ الرمز. |
| انتهت صلاحية الشهادة | انتهت مدة صلاحية الشهادة. |
| الشهادة غير صالحة | لم تجتز الشهادة التحقق: موقّعة ذاتيًا، أو صادرة لاسم آخر، أو من مُصدِر غير معروف. ويُحفظ الرمز. |
| رمز حالة غير متوقع | فشل **رمز الحالة ضمن**. تعرض الرموز المتوقعة والرمز المرصود. |
| لم يتحقق معيار | فشل معيار للمحتوى أو JSON أو ترويسة. تعرض القيمتين المتوقعة والمرصودة، حتى 200 حرف لكل منهما. |
| استجابة بطيئة | فشل **مدة الاستجابة أقل من**. تعرض الحد والزمن المرصود. |
| إعادات توجيه أكثر من الحد | أكثر من 10 إعادات توجيه. |
| خطأ غير معروف | أي شيء آخر. ويُحفظ نص الخطأ الخام بجانبه. |

إذا فعّلت **تجاهل أخطاء TLS**، لا تقع علتا الشهادة.

## مثال

عنوان الصحة لواجهة برمجية، `https://api.example.com/health`، يجيب:

```json
{ "status": "ok", "db": { "latency_ms": 12 } }
```

اضبط **عنوان الرابط** على `https://api.example.com/health`، وأبقِ **رمز الحالة ضمن** `2xx`، وأضف **قيمة JSON تساوي** بالمسار `status` و**القيمة** `ok`، واضبط **حد التعثّر** على `800`.

- الاستجابة `503` متعطّلة بعلة «رمز حالة غير متوقع»، والمتوقع `2xx`، والمرصود `503`. ولا يُقيَّم معيار JSON.
- الاستجابة `200` مع `"status": "starting"` متعطّلة بعلة «لم يتحقق معيار»، والمتوقع `ok`، والمرصود `starting`.
- الاستجابة `200` مع `"status": "ok"` التي تستغرق 1.2 ثانية متعثّرة.

اضغط **افحص الآن** قبل الحفظ لترى رمز الحالة، ومدة الاستجابة، وحجم المحتوى، ونتيجة كل معيار، والاستجابة نفسها.
